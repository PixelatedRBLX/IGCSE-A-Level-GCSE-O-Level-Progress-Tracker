An interactive, self-contained single-page web application designed for students (such as IGCSE, GCSE, O-Level, 
AS & A-Level, and Edexcel IAL candidates) to log their past paper attempts, input marks, and instantly track their performance,
estimated grades, and progress over time.

Multi-Board & Qualification Support

    Supports Cambridge IGCSE, Cambridge O-Level, Cambridge AS & A-Level, Edexcel International GCSE (IGCSE), Edexcel International A Level (IAL), UK GCSE (AQA, Edexcel, OCR), and UK A Level (AQA, Edexcel, OCR).

    Automatically tailors available subjects, tiers, paper variants, and components based on the selected qualification.

Computes percentage scores and weighted averages across papers.

Automatically estimates grade boundaries (using May/June 2026 threshold standards built into the dataset) once a complete exam set is finished.

Filter logs by specific subjects or view an aggregated overview across all subjects and time periods.

Displays quick statistical summaries including total papers completed, average scores, and complete set averages.

Save as Excel (.xlsx): Generates a fully formatted spreadsheet containing log details and set breakdowns using a custom in-browser ZIP/XLSX builder with no external libraries required.

Save as PDF: Compiles a clean, printable PDF summary report complete with statistics, grade estimates, and structured tables.
